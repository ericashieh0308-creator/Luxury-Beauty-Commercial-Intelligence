# Executive strategy report template

Use this eight-section framework after source licensing and real-data validation. Tag each statement **Observed fact**, **Analytical inference**, **Simulated result**, or **Management recommendation**. Record the input file checksum, dataset vintage, table, filter, observation count and metric definition beside each quantitative exhibit.

1. **Executive Summary.** Record the decision, three findings, associated uncertainty and action owner.
2. **Market Context.** Use dated, verified benchmark registry entries with metric scope and units.
3. **Commercial Performance.** Add assortment count, coverage, share and snapshot availability tables. Show known denominators beneath charts.
4. **Pricing and Brand Positioning.** Plot category price distributions and median gaps. Verify comparable category and variant definitions.
5. **Cross-Snapshot and Cross-Market.** Add a match funnel, paired price-gap distribution and FX stress. Call out coverage and selection.
6. **Financial Scenarios.** Use the [separate illustrative case](illustrative-financial-case.md) and update with outputs of the model if assumptions change.
7. **Recommendations.** Rank by financial sensitivity, strength of evidence, implementation effort and owner.
8. **Limitations and Next Steps.** Include sampling, manual match and review-validation outcomes, unverified data, and requirements for transaction-level evidence.
